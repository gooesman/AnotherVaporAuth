# GooeSteamKit 隐私说明

更新日期：2026-10-14。本文适用于 **GooeSteamKit**，即 gooesman 基于 freefrank
的 AVA 维护的独立 Fork，提供 Windows 和 Android 版本。此前两端分别名为
**AVA-pc** 和 **AVA Fork**。名称和图标变更保留原有数据路径及 Android 包名、签名，
现有 AVA Fork 用户无需重新导入账号。

Steam 账户和验证器密钥保存在你的设备上。登录、库存、市场和交易请求使用
Valve 的服务，并按相应操作使用所需的账户及会话信息，不经过本分支的中转服务器。
即使未配置订阅，也优先使用检测到的外部 HTTP 代理或系统 VPN／TUN 线路。
开启可选内置接管后，未检测到外部线路时使用你选择的订阅节点。
其运营者可以看到目标地址、连接时间和流量等信息；Steam 的正常 TLS 证书校验保持开启。

备用登录码只在你点击发送短信并提交验证码后请求。所选账户的会话及输入的验证码
通过 HTTPS 发给 Valve；返回的备用码仅留在页面内存，离开页面、隐藏应用或锁库时
清除，不写入账户文件、日志或 WebDAV。

首页在前台且账户库已解锁时，使用现有会话向 Valve 查询待确认、未读消息和好友申请数量，
低频刷新并复用内存缓存。打开通知页才读取通知及好友申请，默认优先显示未读、折叠已读历史。
通知正文和物品详情响应仅保存在页面内存，不写入同步文件。可见的库存通知按需向 Valve
查询所指单个物品的详情，包括名称和图片标识，不读取整份库存；公开缩略图复用设备上的
Steam CDN 图片缓存。库存、交易报价和好友申请可进入相应应用内页面，其余类型可进入
Steam 通知中心查看。
标为已读、忽略通知、处理好友申请及撤销其他设备授权均由你显式操作，不自动处理交易或移除验证器。
复制名称或 SteamID 只写入设备剪贴板，不为复制操作发起网络请求。

Steam 加速是可选项，默认手动启动。订阅地址和筛选后的节点凭据保存在本机安全
存储中，与账户文件分开。配置 WebDAV 并开启“同步应用设置”后，订阅地址、筛选后的
缓存节点和选中节点会加入以同步口令加密的设置文档；清除订阅也会同步到其他设备。
自动启动偏好、运行状态、本地监听凭据和端口、外部代理及 VPN 检测结果仍由各设备
独立保存。接收同步订阅不会获取节点或自动开启加速。旧版不支持同步这些字段；旧文档
缺少字段时，新版保留本机订阅。请两端都升级后使用订阅同步。
点击“更新节点”时访问订阅服务；开启自动启动后，若没有
缓存节点，启动时也可能获取订阅。支持 HTTP／HTTPS 订阅；地址中的用户名和密码
只向该来源发送为 HTTP Basic 认证。HTTP 订阅的地址、凭据和响应以明文传输；
这不会改变 Steam 连接和组件下载的 TLS 校验。Windows 首次使用时按需下载固定版本组件，
依次尝试 `axisnow.gh-proxy.org`、`v4.gh-proxy.org` 和上游 GitHub Release。
组件下载使用独立直连客户端，不携带订阅或应用代理凭据；已有系统 VPN／TUN 仍可能承载
这些流量。服务方可以看到客户端 IP、公开组件路径、请求时间和流量。压缩包和解压后的
程序均须通过应用内固定的 SHA-256 校验才能使用。Android 安装包内含同一组件。
组件使用受保护的本地监听端口，通过内存
接收配置，不保留运行日志。GooeSteamKit 在应用可见时每 5 秒检测本机系统代理及 VPN 信息，
返回前台时也会检查，不上传这些信息，也不修改系统代理、DNS 或证书。开启本次自动切换后，
外部线路出现时暂停内置组件，外部关闭且环境明确时恢复内置；“暂停自动切换”取消本次内置接管，
仍跟随外部线路。下次启动的偏好保留在本机。环境未知、未解析的 PAC 或自动发现设置会阻止
内置启动；应用不执行 PAC 脚本。隐藏应用时暂停定期检测。线路变化不会自动重发在途的写入请求。
连接检查通过当前实际线路访问 Steam 公开接口和社区，不携带账户 Cookie 或令牌。
检查在相关线路变化、返回前台且旧结果过期后或你手动点击时进行，不持续轮询 Steam；检查结果只说明
网络连通情况，不代表账户已登录或获准交易。

市场收藏的公开商品标识、展示信息和所选报价币种保存在本机 `market_favorites.json`。
开启“同步应用设置”后，这些字段也加入加密设置文档；缓存价格与在售数量不参与同步。
仅市场页及已启用概览收藏卡片中当前可见的商品向 Steam 请求报价，不在后台持续轮询价格。
概览卡片的显示开关、顺序和电脑端宽度都是本机偏好，不参与同步。

可选的 WebDAV 同步在你配置后才启用，把加密后的账户载荷及已启用的精选设置文档
发送到你指定的服务器。服务器可见的同步元数据包括 SteamID、修订号及载荷摘要，
不包含明文订阅凭据。
本地／远程对比在本机解密载荷，可显示公开账户名、SteamID、收藏商品与普通设置的差异。
账户密钥、验证器 URI、订阅地址和节点凭据均隐藏，只提示敏感内容有变化。
每次明确上传／拉取处理一个账户或整份设置文档，设置包含收藏与订阅；两端设置均有改动时等待选择。
本地调试日志可能包含账户名和 SteamID，应用不会自动上传。框选 Steam 登录二维码
时，截图只在本机内存中识别，不保存或上传截图。对已导入账户明确点击“打开 Steam 并登录”或“切换账号”后，
也可读取本次新开且已核实来源的本机 Steam 登录窗口可见内容；再次核对同一窗口和二维码后，
使用所选账号向 Valve 提交一次批准，不自动批准其他待处理的登录请求。取消、锁库或离开页面
会停止后续批准，但不能撤销已提交的请求。结果仅核验 Steam 客户端当前本机账号，不代表
服务器会话在线。图像始终留在本机内存中。

本分支不验证 Pro 订阅、不兑换购买、不加载广告，也不刷新已有权益凭据。本地功能
无需原版订阅。旧权益记录为兼容而原样保留；不会伪造权益凭据，也不会因此获得
原作者运营的在线服务权限。

在设置中打开更新页面时，应用查询本分支的公开 GitHub Releases。点击下载后，
自动下载优先访问 GH-Proxy 的 `axisnow.gh-proxy.org`，再尝试 `v4.gh-proxy.org`，
失败时回退 GitHub；下载前也可选择只用 GitHub 官方源。电脑和手机的下载源选项始终可见，
没有新版或版本检查失败时也可以查看。加速源使用独立直连客户端，
不携带应用代理凭据；已有系统 VPN／TUN 仍可能承载这些流量。镜像运营者可以看到
你的 IP、公开文件路径、客户端标识、请求时间和流量。请求不携带 Steam 账户、验证器
密钥、权益凭据或订阅地址。版本和可信摘要仍直接读取 GitHub 官方 API。官方请求优先
复用检测到的系统 HTTP 代理，没有外部代理时可使用已运行的内置加速；代理运营者
可看到连接的地址、时间和流量。正常 TLS 校验保持开启，不为更新启动额外代理。大文件可并行
请求多个区间。应用按照 GitHub 提供的 SHA-256 摘要校验文件，经你确认后交给系统
安装程序。应用不查询原版更新服务，也不在后台安装更新。
反馈入口仅在浏览器打开本分支的 GitHub Issues，不会自动发帖或
附加报告。你自行提交到 GitHub 的内容适用其规则，并可能公开。其他外部链接
由浏览器打开各自网站。

广告和反馈中转服务不会被本分支默认构建使用。

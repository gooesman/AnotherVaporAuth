# AVA 本分支隐私说明

更新日期：2026-10-11。本文适用于 gooesman 基于 freefrank 的 AVA 维护的独立
Fork，包括 Windows 上的 **AVA-pc** 和 Android 上的 **AVA Fork** 试用包。

Steam 账户和验证器密钥保存在你的设备上。登录、库存、市场和交易请求使用
Valve 的服务，并按相应操作使用所需的账户及会话信息，不经过本分支的中转服务器。
开启可选加速后，Steam 加密连接经过你选择的订阅节点或检测到的外部代理。
其运营者可以看到目标地址、连接时间和流量等信息；Steam 的正常 TLS 证书校验保持开启。

备用登录码只在你点击发送短信并提交验证码后请求。所选账户的会话及输入的验证码
通过 HTTPS 发给 Valve；返回的备用码仅留在页面内存，离开页面、隐藏应用或锁库时
清除，不写入账户文件、日志或 WebDAV。

Steam 加速是可选项，默认手动启动。订阅地址和筛选后的节点凭据保存在本机安全
存储中，不参与账户同步。点击同步节点时访问订阅服务；开启自动启动后，若没有
缓存节点，启动时也可能获取订阅。支持 HTTP／HTTPS 订阅；地址中的用户名和密码
只向该来源发送为 HTTP Basic 认证。HTTP 订阅的地址、凭据和响应以明文传输；
这不会改变 Steam 连接和组件下载的 TLS 校验。Windows 首次使用从固定的上游 GitHub Release
下载组件；Android 安装包内含同一组件。组件使用受保护的本地监听端口，通过内存
接收配置，不保留运行日志。AVA 在本机检测系统代理及 VPN 信息以暂停内置组件，
不会上传这些信息，也不修改系统代理、DNS 或证书。
连接检查通过当前实际线路访问 Steam 公开接口和社区，不携带账户 Cookie 或令牌。
检查在相关线路变化、返回前台且旧结果过期后或你手动点击时进行，不持续轮询 Steam；检查结果只说明
网络连通情况，不代表账户已登录或获准交易。

可选的 WebDAV 同步在你配置后才启用，把加密后的账户数据发送到你指定的服务器。
本地调试日志可能包含账户名和 SteamID，应用不会自动上传。框选 Steam 登录二维码
时，截图只在本机内存中识别，不保存或上传截图。

本分支不验证 Pro 订阅、不兑换购买、不加载广告，也不刷新已有权益凭据。本地功能
无需原版订阅。旧权益记录为兼容而原样保留；不会伪造权益凭据，也不会因此获得
原作者运营的在线服务权限。

在设置中打开更新页面时，应用查询本分支的公开 GitHub Releases。点击下载后，
安装包来自 GitHub 发布文件服务器；这些请求不携带 Steam 账户、验证器密钥或
权益凭据。应用按照 GitHub 提供的 SHA-256 摘要校验文件，经你确认后交给系统
安装程序。应用不查询原版更新服务，也不在后台安装更新。
反馈入口仅在浏览器打开本分支的 GitHub Issues，不会自动发帖或
附加报告。你自行提交到 GitHub 的内容适用其规则，并可能公开。其他外部链接
由浏览器打开各自网站。

本分支没有新增跟踪或统计，保留原作者版权、MIT 许可及第三方声明。仓库根目录的
PRIVACY.md 与 PRIVACY_ZH.md 是原项目政策，保留供参考；其中已经关闭的支付、
广告和反馈中转服务不会被本分支默认构建使用。
